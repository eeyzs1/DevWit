# DevWit v0.6.0 Release Notes

## Highlights — First-run experience & cost transparency

v0.6.0 ships three slices that close the loop from first launch to first real task:

### 1. Cost budget dashboard (Settings → 成本预算)

- Per-period budget with threshold alerting: set a limit (per session / day / month), get a live in-app alert the moment usage crosses it
- 30-day cost trend bars plus a Top-5 sessions breakdown — see exactly which sessions drove spend
- Export the ledger as CSV or JSON with one click
- Costs are only ever reported for priced models; unpriced runs are tracked separately and never fabricated

### 2. First-run authorization-gate tour

- Right after the context-panel tour, a short guided pass through the authorization gate teaches why DevWit asks before file writes and shell commands — and how the allow-list learns
- Runs once, skippable, persisted in settings

### 3. One-click sample project (Onboarding → 新建示例项目)

- Generates a complete, zero-dependency TypeScript todo web app (strict tsconfig, `npm run build` = `tsc`, no bundler) in any folder you pick
- README guides three tasks: explain the code, find and fix a planted bug, then install/build/run — a hands-on tour of the context panel, the authorization gate, and diff review
- Overwrite-safe: you choose the target directory

## Still core

- Transparent context panel with per-item token costs and toggles
- Authorization gate for file writes and shell commands
- TypeScript + Python LSP, Git, DAP debugging, MCP, multi-agent orchestration
- MIT, free, no accounts — telemetry opt-in off by default

## Install

- Windows: `DevWit.Setup.0.6.0.exe` (unsigned — SmartScreen may warn until code signing)
- macOS: `brew install --cask eeyzs1/tap/devwit` then `xattr -dr com.apple.quarantine /Applications/DevWit.app`
- Linux: AppImage or deb from this release
