# DevWit v0.7.0 Release Notes

## Highlights — Remote MCP (Streamable HTTP) & real external server validation

v0.7.0 makes DevWit's MCP support truly remote: connect to URL-based (hosted / cloud) MCP servers over Streamable HTTP — not just local subprocesses — and see exactly what the agent called.

### 1. Remote MCP over Streamable HTTP (transport: http)

- New `McpHttpClient`: single-endpoint POST, `Accept: application/json, text/event-stream`, required MCP headers (`MCP-Protocol-Version` / `Mcp-Method` / `Mcp-Name` with base64 sentinel for non-ASCII), JSON or request-level SSE responses, timeout/abort, and `DW_MCP_HTTP_*` error codes
- Unified `McpTransport` interface so stdio and http servers share one manager, one tool-injection path, and one authorization gate
- Config is transport-aware: `stdio` needs `command/args/env`; `http` needs a valid `http(s)` `url` (+ optional `headers`, optional credentials-backed `auth`); stdio stays fully backward compatible
- Settings → MCP now has a transport dropdown (本地进程 / 远程-Streamable HTTP) plus URL and headers fields

### 2. Reaches real public MCP servers (protocol-version negotiation)

- Real public MCP servers (e.g. Context7 at `mcp.context7.com`) use `2025-06-18` / `2025-03-26`, which the newest-only client rejected. v0.7.0 negotiates `initialize` across `2026-07-28 → 2025-06-18 → 2025-03-26`, sends the modern `Mcp-Method` / `Mcp-Name` headers only for the newest revision, sends `_meta.protocolVersion` only on `initialize`, and captures the server's self-reported `serverInfo`
- Verified live: DevWit connected to the real external **Context7** MCP (negotiated `2025-06-18`), exposed `resolve-library-id` / `query-docs`, and a real DeepSeek agent called them through the authorization gate — returning real, up-to-date documentation

### 3. Readable MCP metadata in the activity stream

- Agent activity now shows which remote MCP was called: **远程 MCP：<name> · <transport>** plus the server's self-described description — not a bare URL/IP
- The endpoint URL, server version, request arguments and full result are in the expandable detail (click the tool row)
- Community MCP import supports remote payloads (`transport` / `url` / `headers`)

## Still core

- Transparent context panel with per-item token costs and toggles
- Authorization gate for file writes, shell commands, and now remote MCP tools
- TypeScript + Python LSP, Git, DAP debugging, multi-agent orchestration
- MIT, free, no accounts — telemetry opt-in off by default
