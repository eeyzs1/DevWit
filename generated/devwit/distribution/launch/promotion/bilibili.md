## 录屏实操要点

- 用 OBS 或 Windows 自带 Game Bar（Win+G）录屏，1080p 30fps 够用
- 录屏前先准备好一个真实项目（不要空编辑器），让 LSP/Git/上下文面板有内容可展示
- 上下文面板演示是视频核心，建议提前演练一遍：发起对话 → 展示面板 → 关闭一项 → 展示 token 下降
- 授权门演示：让 Agent 执行一个会改文件的任务，故意慢一点让观众看清授权弹窗
- 不需要露脸，纯录屏 + 配音即可（配音可用手机录，或用剪映的 AI 配音）
- 剪辑用剪映，免费，加字幕自动识别
